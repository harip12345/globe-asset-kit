ATLAS / REUSABLE VIDEO ASSETS

Satu sistem visual.
Bisa diedit untuk topik berikutnya.

Paket ini merekonstruksi karakter globe pada referensi: tekstur satelit, relief dasar laut, atmosfer biru, latar gelap, label geografis, dan gerakan kamera halus. Sumber master adalah kode + JSON + tekstur lokal. HTML menyediakan preview dan kontrol.

Ini implementasi Three.js yang dibuat agar editable oleh AI agent. Ini bukan proyek native After Effects/GEOlayers/VC Orb. Aplikasi/plugin tersebut tidak tersedia pada komputer saat paket dibuat. Kemiripan visual belum berarti identik piksel demi piksel.

Mulai menggunakan

  1. Buka start.cmd dan biarkan terminalnya menyala. Alternatif: jalankan npm start dari folder proyek.
  2. Buka http://127.0.0.1:4173 di browser.
  3. Pilih preset, atur tampilan, kamera, atau konten. Drag globe untuk memutar, scroll untuk zoom.
  4. Gunakan Unduh PNG untuk gambar pada resolusi scene. Aktifkan latar transparan untuk overlay.
  5. Gunakan Simpan JSON untuk menyimpan perubahan. Perubahan editor tidak otomatis menimpa file sumber.

Jika folder dipindahkan tanpa node_modules, jalankan npm ci terlebih dahulu. Setelah dependensi tersedia, editor dan tekstur dapat digunakan offline. Node.js diperlukan untuk server lokal.

Struktur scene JSON

PropertiArti
versionVersi schema: 1.
name, duration, fpsNama, durasi dalam detik, frame per detik.
width, heightResolusi hasil; 1080×1920, 1920×1080, atau ukuran lain hingga 4096.
texturePath lokal dalam folder assets/. Tekstur persegi panjang equirectangular 2:1.
styleexposure, saturation, ocean, oceanMix, fill, atmosphere, halo.
cameralat, lon, zoom, roll dan keyframes. Jika keyframes kosong, kamera statis.
labelsArray objek {text, lat, lon, color}.
routesArray {from:[lat,lon], to:[lat,lon], color, start, end, altitude}.
objectsArray {type, lat, lon, altitude, scale, orbitSpeed, inclination}; type: satellite, ship, glb. Model glb juga memerlukan asset.
title, subtitleTeks opsional. Kosongkan untuk aset bersih.
background, transparentWarna latar #RRGGBB dan pilihan alpha.

Koordinat memakai [latitude, longitude] dalam derajat. Utara/timur positif. Altitude relatif terhadap radius bumi: 0.025 berarti 2,5% radius di atas permukaan. Ini satuan komposisi visual, bukan kilometer.

"camera": {
  "lat": 19, "lon": -168, "zoom": 1, "roll": 0,
  "keyframes": [
    {"time": 0, "lat": 19, "lon": -168, "zoom": 0.96},
    {"time": 12, "lat": 23, "lon": -158, "zoom": 1.06}
  ]
}

Keyframe diurutkan menurut waktu. Kamera mengambil lintasan longitude terpendek, termasuk melintasi garis tanggal. Gerak dihitung langsung dari waktu absolut agar frame ekspor konsisten. Menggeser kontrol kamera di editor mengubah shot menjadi statis; gunakan tombol orbit untuk membuat gerakan baru.

Menambahkan model penyu atau objek lain

Simpan model GLB tidak terkompresi beserta tekstur tertanam ke assets/models/. Draco/KTX2 dan decoder eksternal belum dikonfigurasi. Contoh:

"objects": [{
  "type": "glb", "asset": "assets/models/penyu.glb",
  "lat": -0.8, "lon": 133.2,
  "altitude": 0.03, "scale": 0.09,
  "orbitSpeed": 0, "inclination": 0
}]

Model otomatis dinormalisasi berdasarkan dimensi terbesarnya. Local Y diarahkan menjauhi pusat bumi. Aset mungkin perlu orientasi tambahan sesuai pembuatannya. Animasi embedded dapat diputar berdasarkan waktu. Model penyu realistis belum disertakan; kapal dan satelit bawaan adalah model ilustrasi yang dibuat di kode.

Ekspor bahan video

PNG dapat diekspor dari editor tanpa tool tambahan. Ekspor otomatis menggunakan Playwright/Chromium dan FFmpeg. Pada komputer ini renderer memakai runtime yang tersedia. Untuk komputer lain:

npm install --save-dev playwright
npx playwright install chromium
# Install FFmpeg dari ffmpeg.org, lalu pastikan ffmpeg ada di PATH.

Perintah dijalankan dari folder proyek. Server render sementara dijalankan otomatis lalu ditutup.

# PNG resolusi penuh pada detik ke-4
node scripts/render.mjs --scene pasifik --format png --time 4 --out exports/globe.png

# PNG transparan
node scripts/render.mjs --scene pasifik --format png --transparent --out exports/globe-alpha.png

# Video MP4, 1080 × 1920, 30 fps, durasi sesuai scene
node scripts/render.mjs --scene rute --format mp4 --out exports/rute.mp4

# Preview lebih ringan
node scripts/render.mjs --scene rute --format mp4 --width 720 --height 1280 --out exports/preview.mp4

# PNG sequence dengan alpha untuk After Effects / editor lain
node scripts/render.mjs --scene pasifik --format frames --transparent --out exports/pasifik-frames

# Scene baru dari AI agent
node scripts/render.mjs --scene scenes/indonesia-jepang.json --format mp4 --out exports/indonesia-jepang.mp4

MP4/H.264 tidak menyimpan alpha. Untuk layer transparan, gunakan PNG sequence. Frame dimulai pada t=0 dan berakhir satu frame sebelum durasi. Ekspor tidak menyertakan suara. File .render.json disimpan bersama hasil agar konfigurasi render dapat dilacak. Override tersedia: --width, --height, --fps, --seconds, --time, --transparent. Render lebih lama daripada durasi scene akan mempertahankan frame terakhir.

Jika Chromium tidak ditemukan: gunakan GLOBE_CHROMIUM_PATH. Untuk runtime Playwright alternatif: GLOBE_PLAYWRIGHT_PATH. Untuk FFmpeg alternatif: FFMPEG_PATH. Kecepatan render bergantung pada GPU/CPU dan resolusi.

Hubungan dengan After Effects, GEOlayers dan VC Orb

PNG, PNG sequence, dan MP4 dari paket ini bisa dimasukkan ke After Effects sebagai bahan video. Script import-render.jsx membantu membuat komposisi dari hasil render. Tekstur NASA juga dapat dipakai sebagai sumber tekstur pada workflow globe native.

GEOlayers dan VC Orb tetap memerlukan instalasi, lisensi yang sesuai, dan pengaturan proyek native. Kode Three.js tidak otomatis berubah menjadi proyek native yang semua propertinya dapat diedit di After Effects. Master editable untuk paket ini tetap kode dan scene JSON.

Batas detail geografis

Tekstur 5400×2700 cocok untuk globe dan tampilan wilayah. Ini citra komposit historis, bukan citra real-time. Zoom hingga pantai/jalan membutuhkan citra tile resolusi tinggi dan, jika perlu, terrain. Paket ini belum menyediakan integrasi Cesium, Google Earth Studio, atau API citra satelit. Tidak ada janji zoom tanpa batas dari satu tekstur.
