# Arsip handoff godwit

Sumber: lampiran Google Drive pada brief Instinct yang dibagikan pengguna, 25 Oktober 2026.

`README-HANDOFF.md` dan `bird-object.patch` disimpan sebagai catatan asal. **Jangan menjalankan `git apply` pada patch ini**: dukungannya sudah diadaptasi ke engine utama dengan schema umum `followRoute`, sprite, dan camera follow.

README asal melaporkan tes dan render pada clone agent sebelumnya. Laporan itu bukan hasil pemeriksaan engine gabungan ini. Tidak ada tes atau render uji baru dijalankan pada tahap integrasi atas permintaan pengguna. Lihat [panduan terbaru](../MOTION.md).

Empat PNG dan sembilan scene asli disalin ke assets/ dan scenes/. Lisensi terpisah tidak dinyatakan dalam paket handoff; provenance disimpan dalam assets/manifest.json.
